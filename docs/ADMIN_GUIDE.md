## Доступ к Панели Администратора

Административная панель доступна только пользователям с ролью `admin`.
*   URL: `/admin` (ссылка в личном кабинете).
*   Для выдачи прав администратора другому пользователю необходимо изменить его роль в базе данных или использовать команду Artisan (будет добавлена позже).

## Пользователи и Финансы

В разделе **Пользователи** вы можете:
1.  Просматривать список всех зарегистрированных клиентов.
2.  Искать пользователей по Email.
3.  **Пополнять баланс**: В карточке пользователя нажмите "Пополнить баланс" (операция `admin_deposit`). Это единственный способ зачислить средства на данный момент.
4.  Списывать средства (штрафы/корректировки).
5.  Просматривать историю финансовых операций конкретного пользователя.
6.  Блокировать/Разблокировать пользователей.

## Заказы и Серверы

Раздел **Заказы** — основной инструмент управления услугами.

### Создание Заказа (Ручное)
Если нужно выдать сервер вручную (например, партнеру или в качестве теста):
1.  Нажмите **Создать заказ**.
2.  Выберите пользователя.
3.  Выберите тариф (Infrastructure Service).
4.  Укажите срок действия (по умолчанию +30 дней).
5.  Выберите метод оплаты:
    *   **Списать с баланса**: Проверит наличие средств у пользователя и спишет их.
    *   **Бесплатно**: Создаст активный заказ без списания (подарок).
6.  Сервер будет установлен автоматически в Pterodactyl.

### Управление Статусами
В карточке заказа можно изменить статус:
*   **Active (Активен)**: Сервер работает. Если переключить на этот статус, система попытается **разморозить** (unsuspend) сервер в Pterodactyl.
*   **Suspended (Приостановлен)**: Сервер заморожен за неуплату. При переключении система **заморозит** (suspend) сервер в Pterodactyl.
*   **Cancelled (Отменен)**: Услуга прекращена. Сервер может быть удален вручную или автоматически.
*   **Failed (Ошибка)**: Установка не удалась. В карточке будет показан текст ошибки (JSON ответ от Pterodactyl) для диагностики.

### Смена Тарифа
Кнопка **Сменить тариф** позволяет изменить услугу, привязанную к заказу.
*   Цена продления обновится автоматически.
*   **Важно**: Ресурсы сервера в Pterodactyl (CPU/RAM/Disk) пока **не обновляются автоматически** при смене тарифа. Их нужно изменить вручную в панели Pterodactyl (Build Configuration). Это будет исправлено в будущих обновлениях.

### Возврат Средств
Кнопка **Оформить возврат**:
1.  Автоматически рассчитывает сумму за неиспользованные дни.
2.  Позволяет выбрать тип возврата:
    *   **На баланс**: Деньги зачисляются на счет пользователя, заказ отменяется.
    *   **Внешний**: Деньги возвращаются вручную (на карту), в системе только фиксируется факт возврата, заказ отменяется.

## Услуги и Тарифы

Настройка продаваемых услуг происходит в разделе **Инфраструктура**.

### Создание Категорий
Категории (Minecraft, Rust, VPS) группируют услуги.
*   **Slug**: URL-адрес категории (генерируется автоматически).
*   **Сортировка**: Порядок отображения.

### Создание Услуг (Services)
Внутри категории создаются конкретные тарифы.
*   **Название**: Отображается клиенту.
*   **Цена**: Ежемесячная стоимость.
*   **Характеристики (JSON)**: `cpu`, `ram`, `disk`, `databases`, `allocations`, `backups`. Эти параметры передаются в Pterodactyl при создании сервера.
*   **Egg ID / Nest ID**: ID яйца и гнезда в Pterodactyl. Обязательно для корректной установки игрового сервера.
*   **Docker Image**: Образ контейнера (например, `ghcr.io/pterodactyl/yolks:java_17`).
*   **Startup Command**: Команда запуска.

## Поддержка (Тикеты)

Раздел **Тикеты** позволяет общаться с клиентами.
*   Вы видите список открытых тикетов.
*   Можете отвечать, закрывать тикеты, менять приоритет.
*   В тикете видна ссылка на связанный заказ (если есть), что ускоряет диагностику.
