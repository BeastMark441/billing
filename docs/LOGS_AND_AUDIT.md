# Логи / аудит / очистка

## Типы логов

* `UserLog` — действия пользователей (логин/логаут/регистрация и т.п.).
* `AuditLog` — системный аудит (платежи, операции админки, чеки и т.п.).
* `BalanceLog` — финансовая история (пополнения/списания/продления/покупки).

## Админ‑страницы

### Логи

* `/admin/logs` — просмотр `AuditLog` и `UserLog` с фильтрами.
* Очистка логов доступна только супер‑админу:
  - очистка по пользователю + фильтры;
  - очистка всех логов.

### Финансы

* `/admin/finance` — общий список `BalanceLog`.
* Удаление отдельной записи и удаление по фильтру доступны только супер‑админу.

## Супер‑админ

Супер‑админ определяется конфигурацией:
* `SUPER_ADMIN_USER_IDS` — список user_id через запятую.
* `SUPER_ADMIN_EMAILS` — список email через запятую.

Опасные операции всегда требуют:
* подтверждение фразой (`DELETE`, `DELETE ALL`, `DELETE FINANCE`);
* ввод текущего пароля.
