# Система биллинга NODEUM

Это комплексная система биллинга и управления, разработанная для хостинг-провайдеров и специально интегрированная с панелью Pterodactyl. Она обеспечивает автоматическое создание пользователей, предоставление серверов и управление услугами.

## Обзор проекта

Система биллинга NODEUM предоставляет удобный интерфейс для заказа и управления игровыми серверами и другими инфраструктурными услугами.

**Ключевые возможности:**
*   **Автоматическое предоставление:** автоматически создаёт пользователей и серверы в Pterodactyl после оплаты.
*   **Управление инфраструктурой:** организация услуг по категориям и подкатегориям.
*   **Управление заказами:** панель администратора для управления заказами, приостановки/возобновления услуг и обработки отмен.
*   **Система тикетов поддержки:** встроенная служба помощи для пользователей.
*   **Личный кабинет пользователя:** чистый и современный интерфейс для просмотра активных услуг и данных аккаунта.

## Инструкции по развёртыванию

### Требования
*   PHP 8.2 или выше
*   Composer
*   MySQL/MariaDB
*   Node.js и NPM (для фронтенд-ресурсов)
*   Рабочий экземпляр панели Pterodactyl

### Шаги установки

1.  **Клонирование репозитория**
    ```bash
    git clone <repository-url>
    cd billingnodeum
    ```

2.  **Установка зависимостей**
    ```bash
    composer install
    npm install
    ```

3.  **Настройка окружения**
    Скопируйте пример файла окружения и настройте его:
    ```bash
    cp .env.example .env
    ```
    Обновите файл `.env` вашими данными базы данных и учётными данными Pterodactyl:
    ```env
    DB_DATABASE=your_database
    DB_USERNAME=your_username
    DB_PASSWORD=your_password

    PTERODACTYL_URL=https://panel.yourdomain.com
    PTERODACTYL_CLIENT_KEY=your_client_api_key
    PTERODACTYL_APP_KEY=your_application_api_key
    ```

    Дополнительно (платежи / чеки / админ-доступ):
    ```env
    TBANK_TERMINAL_KEY=
    TBANK_PASSWORD=
    TBANK_API_URL=https://securepay.tinkoff.ru/v2/
    TBANK_WEBHOOK_URL=https://yourdomain.com/payments/webhook

    ORG_NAME=NODEUM
    ORG_SITE=https://yourdomain.com
    ORG_INN=
    ORG_KPP=
    ORG_ADDRESS=""
    ORG_PHONE=""
    ORG_EMAIL=""

    SUPER_ADMIN_USER_IDS=1,2
    SUPER_ADMIN_EMAILS=
    ```

4.  **Генерация ключа приложения**
    ```bash
    php artisan key:generate
    ```

5.  **Запуск миграций**
    ```bash
    php artisan migrate
    ```

6.  **Сборка фронтенд-ресурсов**
    ```bash
    npm run build
    ```

7.  **Настройка cron-задания**
    В проекте есть команды для периодического запуска. Их можно повесить на cron вручную (или добавить в scheduler на вашей стороне):
    ```bash
    # проверка истечения / автопродления
    0 * * * * cd /path-to-your-project && php artisan billing:check-expirations

    # синхронизация статусов с Pterodactyl
    */10 * * * * cd /path-to-your-project && php artisan billing:sync-status

    # дожим pending платежей T-Bank (полезно, если вебхук недоступен)
    */5 * * * * cd /path-to-your-project && php artisan payments:reconcile-tbank --minutes=5 --limit=50
    ```

### После установки
*   Создайте администратора или выполните сидирование базы данных, если доступны сидеры.
*   Войдите в панель администратора и настройте категории инфраструктуры и услуги.
*   Убедитесь, что у узлов Pterodactyl есть свободные allocations для назначения.
